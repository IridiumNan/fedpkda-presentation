# 现有问题与痛点

## 2.1 数据异构性问题（Non-IID）

- 各客户端数据分布不一致
- 导致全局模型在不同客户端上表现差异大
- 引出个性化联邦学习（PFL）的必要性

## 2.2 隐私泄露风险

- 梯度/特征传输并非绝对安全
- DLG（Deep Leakage from Gradients）攻击原理简述
- 攻击者可从梯度中重建原始数据

## 2.3 本地表示偏差

- PFL 中客户端过度个性化
- 本地模型在未见样本（Unseen Samples）上表现下降
- 根源：缺乏跨客户端共识信息的引导

## 2.4 现有方法的局限

- 隐私保护方法（DP）→ 噪声损害模型效用
- 参数解耦方法 → 忽略跨客户端信息
- 简单原型方法 → 未充分处理隐私和噪声问题
