# 联邦学习基础概念

## 1.1 联邦学习的定义与背景

- 数据隐私日益重要的时代背景
- 传统机器学习：中心化收集数据，集中训练
- 联邦学习：数据留在本地，模型参数/梯度通信

## 1.2 联邦学习的基本工作流程

- 服务器初始化全局模型
- 分发模型至各客户端
- 客户端使用本地数据训练
- 上传模型更新（梯度/权重）
- 服务器聚合更新，生成新全局模型
- 迭代直至收敛

## 1.3 联邦学习的典型架构

- Client-Server 架构
- 通信轮次（Communication Round）概念
- 参与率（Participation Rate）概念
